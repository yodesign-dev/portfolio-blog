## ⏳ Today's phins

One phin is one sitting on one task: 15, 25 or 45 minutes. Plan them here. When it's time to work, hit "Open the café ↗" on the window: write the task on the paper slip next to the phin timer, and cross it off when the coffee has dripped through. After every phin, the café cat brings out a small keepsake for your shelf.

## 🗺 Change your seat

The window opens in Hanoi. To sit somewhere else, add `?place=` to the window link, for example https://applebin.me/chill/embed?place=dalat. The light follows the real time there.

| Place | Add to the link |
| --- | --- |
| Hanoi, train street | `?place=hanoi-tau` |
| Da Lat | `?place=dalat` |
| Saigon | `?place=saigon` |
| Hue | `?place=hue` |
| Da Nang, Dragon Bridge | `?place=danang` |
| Tien Giang | `?place=tiengiang` |
| Can Tho | `?place=cantho` |
| Mekong countryside | `?place=mientay` |
| Nha Trang | `?place=nhatrang` |

Change the default station: add `station=` and one of `acoustic`, `focus`, `sax`, `lofi`, `study`. To set both, join them with `&`, for example https://applebin.me/chill/embed?place=hue&station=sax
